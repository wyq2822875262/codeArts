如何获取上游 Cookie

收起
网关用网页端的登录态代替你调上游，所以要一段完整的 Cookie。整段粘进来即可，网关自己会从 devclouddevuibjtcftk 里取出 cftk 请求头，并在上游轮转后自动回写，不用手工维护。
  1. 登录网页端

    浏览器打开 https://devcloud.cn-north-4.huaweicloud.com/chat/home，确认已经进入对话界面、右上角能看到自己的账号。没登录拿到的 Cookie 里不会有 SessionID。

  2. 打开开发者工具

    按 F12（Mac 是 ⌥⌘I），切到 Network 面板，筛选器选 Fetch/XHR。

  3. 刷新页面，抓一个 /chat 请求

    按 ⌘R / Ctrl+R 刷新，在请求列表里点任意一条路径以 /chat/ 开头的请求（如 delivery?channel=WEB、sessions）。

  4. 整段复制 Cookie

    右侧切到 Headers → 滚到 Request Headers → 找到 Cookie: 这一行。右键该行选 Copy value，或者双击全选后 ⌘C。要一整行，不要只复制其中几段。

    如果 Headers 里没显示 Cookie，点右侧的 Raw 开关再看；也可以在 Network 列表里右键该请求 → Copy → Copy as cURL，Cookie 在 -H 'Cookie: …' 里。

  1. 登录网页端

    打开 https://devcloud.cn-north-4.huaweicloud.com/chat/home，确认已登录。

  2. 打开 Network 面板

    F12 → 网络，左上筛选选 XHR，然后刷新页面。

  3. 取请求头里的 Cookie

    点任意 /chat/ 请求 → 右侧 消息头 → 请求头 → 找 Cookie → 右键 复制值。

    Firefox 有时把 Cookie 折叠在「已发送的 Cookie」里，展开后逐条拼成 k=v; k=v 也可以，但一定要带上 devclouddevuibjtcftk。

  1. 先启用开发菜单

    Safari → 设置 → 高级 → 勾选「在菜单栏中显示“开发”菜单」。之后按 ⌥⌘I 打开 Web 检查器。

  2. 登录并刷新

    打开 https://devcloud.cn-north-4.huaweicloud.com/chat/home 登录，切到 网络 标签，刷新页面。

  3. 复制 Cookie

    点任意 /chat/ 请求 → 标头 → 请求 → 找到 Cookie 整行复制。

    Safari 不方便复制时，用下面的「控制台一行取」或换用 Chrome 操作。

在网页端按 F12 → Console，粘贴执行，结果可直接粘到「添加账号」里：

copy(document.cookie)

注意：SessionID、cbc-sid、HWWAFSESID 这些是 HttpOnly Cookie，document.cookie 读不到。 如果粘进去校验报「登录态无效」，说明缺了 HttpOnly 那几项，改用上面的 Network 复制法。

想核对一段 Cookie 里到底有哪些键，可以在 Console 跑：

[ 'SessionID', 'cbc-sid', 'devclouddevuibjtcftk', 'HWWAFSESID' ]
  .forEach(k => console.log(k, document.cookie.includes(k + '=') ? '有' : '缺（需用 Network 复制）'))

必须包含的键

Cookie 名作用缺失后果
SessionID主登录态校验直接 401
cbc-sid会话绑定，网关用它识别账号鉴权失败或被判为未登录
devclouddevuibjtcftk上游要求的 cftk 请求头来源缺了会 403；网关会自动提取并轮转回写
HWWAFSESID华为云 WAF 会话票据请求被 WAF 拦，返回验证页
vk附属校验位偶发鉴权失败

常见问题

校验报「登录态无效」/ 401 / 403

多半是 Cookie 过期，或者只复制了半行。重新登录网页端，按上面的步骤整段复制一次。同名账号再添加一次会覆盖更新，不用先删。

粘进去提示含非法字符

复制时带上了全角标点、换行或零宽字符。网关会自动清掉不可打印字符，但如果把换行带进了值里，还是手工删一下。

昨天还能用，今天全挂

上游登录态有有效期，也可能因为换网络 / 换 IP 触发风控。重新取一次 Cookie 即可；账号页点「校验」可以单独确认某个账号是否还活着。

要不要自己填 cftk

不用。留空时网关从 Cookie 里提取；填了也只会用于第一次请求，之后一律以上游轮转回来的值为准。

能只填 SessionID 一项吗

不行，至少要有 SessionID + cbc-sid + devclouddevuibjtcftk，否则对话和签到两条链路都会鉴权失败。

粘贴格式：k=v; k=v; k=v，分号加空格分隔，不要带 Cookie: 前缀。
